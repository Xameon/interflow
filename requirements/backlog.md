# Product Backlog

This backlog contains tasks for the development of the social network for interest-based communities. Tasks are prioritized for upcoming sprints.

---

## All Tasks (10-12)

1. **User Registration and Authentication**  
   Implement user signup, login, and profile management using email/password.

2. **Guest Browsing**  
   Allow non-registered users to browse posts, communities, and comments without interaction.

3. **Create/Edit/Delete Posts**  
   Enable authenticated users to create, edit, and delete their own posts.

4. **Like and Comment on Posts**  
   Implement a system for users to like posts and leave comments.

5. **Create/Edit/Delete Communities**  
   Allow users to create communities, manage membership, and set publishing rights.

6. **Follow/Unfollow Users and Communities**  
   Enable users to follow other users and communities to receive updates.

7. **Search Functionality**  
   Implement search for users, posts, and communities.

8. **Recommendation System**  
   Suggest communities and users based on subscriptions and activity.

9. **Mobile Responsive Design**  
   Ensure the platform works smoothly on mobile and desktop devices.

---

1. **User Registration and Authentication**
2. **Guest Browsing**
