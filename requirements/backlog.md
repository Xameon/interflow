# Product Backlog

This backlog contains tasks for the development of the social network for interest-based communities. Tasks are prioritized for upcoming sprints.

---

## All Tasks (10-12)

1. **Setup Project**
   Create a repository, configure TypeScript, ESLint, and Pretier. Also install the necessary packages and set up a database.

2. **User Registration and Authentication**  
   Implement user signup, login, and profile management using email/password.

3. **Guest Browsing**  
   Allow non-registered users to browse posts, communities, and comments without interaction.

4. **Firebase Integration**
   Integrate Firebase, set up a bucket, and create an image uploader so users can upload images to the platform.

5. **Create/Edit/Delete Posts**  
   Enable authenticated users to create, edit, and delete their own posts.

6. **Like and Comment on Posts**  
   Implement a system for users to like posts and leave comments.

7. **Create/Edit/Delete Communities**  
   Allow users to create communities, manage membership, and set publishing rights.

8. **Follow/Unfollow Users and Communities**  
   Enable users to follow other users and communities to receive updates.

9. **Search Functionality**  
   Implement search for users, posts, and communities.

10. **Recommendation System**  
    Suggest communities and users based on subscriptions and activity.

11. **Mobile Responsive Design**  
    Ensure the platform works smoothly on mobile and desktop devices.

## Sprint Notes

- Duration: 2 weeks
- Goal: Implement the platform's core functionality and provide basic user interaction.
- Results: A pre-built project configured for team development. A functioning registration/authorization system, an image uploader, and the ability for authorized users to view, create, update, and delete posts.
